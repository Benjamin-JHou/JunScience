# Publication-Ready Scientific Figure Generation

## Overview
Generates publication-quality figures for biomedical journals adhering to formatting best practices:
- **Resolution**: 300 to 600 DPI for raster formats (TIFF, PNG); vector formats (PDF, EPS, SVG).
- **Typography**: Sans-serif Arial / Helvetica fonts with distinct hierarchy (Title: 10 pt, Axis labels: 8-9 pt, Tick labels: 7-8 pt).
- **Color Palettes**: Colorblind-accessible palettes (Okabe-Ito, Viridis, Cividis, ColorBrewer).
- **Layout**: Clear panel lettering (A, B, C, D) in upper-left corners.
